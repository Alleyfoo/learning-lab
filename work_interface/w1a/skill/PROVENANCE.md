## Discipline

- **Do not edit this file between A1 and A5.** The five runs must use the exact same
  skill. If the skill is changed, the experiment is invalid and the run dir's sha256
  record (in `RESULTS.json`) will not match a re-grade.
- This revision **replaces** the prose-era `define-lab-process` skill (the one that
  produced the frozen W0B artifact at
  `work_interface/evidence/W0B_process_definition.original.json`). The prose-era
  behavior is preserved as evidence by that frozen artifact; the skill file itself is
  not kept separately because its effect is captured by the artifact it produced.
- The skill teaches the **contract and the closed vocabularies**, not the W0B
  answers. The answers live in `work_interface/w1a/human_answers.md` so that the
  human input is the controlled variable, not the skill.

## How a run uses it

At the start of each desktop Goose session (A1–A5), the operator tells Goose to
`load_skill(name: "define-lab-process")`. Goose reads the live
`skills/define-lab-process/skill.md`. After the session, before grading, the operator
should re-hash the live skill and confirm it still matches the sha256 above; if it
does not, the run is contaminated and must be discarded (not repaired).
