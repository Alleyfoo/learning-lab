### The result and why it matters

| ID | Evidence | Proposal | Result |
| --- | --- | --- | --- |
| F1 | Full (Jakso A) | not_month | supported |
| F2 | Full (Jakso A) | month | insufficient_evidence |
| M1 | Masked ([TARGET]) | not_month | insufficient_evidence |
| M2 | Masked ([TARGET]) | month | supported |

The 2×2 cross (diagonals supported, anti-diagonals insufficient) locates the
mechanism: **directional_prior + lexical_origin**.

- **Direction matters (not proposition-ratifying):** the reviewer endorses
  not_month but withholds on month for the same token. Closed-world default:
  "unfamiliar → not a month."
- **The default is lexical:** hiding "Jakso A" → [TARGET] flips not_month from
  supported to insufficient. The judgement is created by seeing the text.
- **The structure is month-positive (M2 inversion):** with the token hidden, the
  same structural context reads as month (M2=supported) while not_month is
  withheld. The lexical token overrides correct structural reading.
- **F1 reproduces 3B.1** — blind spot run-stable across two independent runs.

The evidence-burden clause "absence of evidence that a header is a month is not
evidence that it is not a month" did NOT prevent the inference: the reviewer
treats "Jakso A doesn't look like a month name" as positive evidence for
not_month. The clause names the fallacy; the model still commits it.

This is the first probe in the programme that **diagnoses a failure mechanism**
rather than only registering the failure.

### Hard stop — honored

No normalization / transformation / country mappings / numeric parsing / multiple
sheets / joins / procedure synthesis, and no symmetric-classification redesign.
3C tested direction × masking contamination only.

  frequency-measured. F1 reproduces 3B.1 (blind spot run-stable across two runs).

  fallback-only, never triggered (C1 was valid-but-wrong, not unparseable). The
  3B.2 negative is NOT evidence against model diversity generally — only against
  that one reviewer on that cell.

  always from once — but the Jakso A over-assertion has now replicated across
  three model families, two contracts, and (in 3C) two independent runs of F1.
- The 3B.1/3C evidence-burden contract was designed knowing the target (stated
  limitation); the controls (3B.1) and the four-condition contrasts (3C) are what
  make the results interpretable.
