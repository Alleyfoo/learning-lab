### The result and why it matters

G3 is the load-bearing test. The classifier (GLM-5.2) reproduced qwen3.5:9b's 2B.5
over-assertion: `Jakso A → not_month` when `unknown` is warranted. Decisively, the
**independent WarrantReviewer (same model, fresh context, no classifier reasoning)
returned `supported`** for that unwarranted classification. The gate therefore
produced `month_columns=[2,3,5,6], ask_human=false` — the silent-omission anti-pattern,
exactly the 2B.3/2B.5 failure mode the architecture was built to prevent.

**The new finding:** structural independence (fresh context, no shared reasoning) did
not produce epistemic independence (different judgement). Same model, same prior,
same blind spot. The escalation signal has now failed across four mechanisms (2A's
unused Escalate, 2B.3 omission, 2B.5 declined unknown, 3A reviewer endorsement);
composition has succeeded twice (2B.5 atomic, 3A orchestrated).

### Hard stop — honored

No normalization / transformation code / country mappings / numeric parsing / multiple
sheets / joins / procedure synthesis were added. 3A ended at "is manager + narrow agents
+ deterministic gate viable?" Answer: viable for composition, not for same-model
warrant-based escalation.
