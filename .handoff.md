## Known issues / limitations

- **3E:** one run per reviewer cell (six cells) + one orchestrator-disposition
  call, all on GLM-5.2, no seed control. The PASS is a confirmed preregistered
  prediction (expected gate output frozen before any probe ran) but a single
  sample — reliability unmeasured. The frozen specialist is one run's output;
  3E proves the review+gate layer against one specific bad judgement, not the
  space of possible bad judgements. The comparison gate is new code (simple,
  deterministic, auditable, dry-run-verified over all six input combinations).
  The orchestrator agreement is partly deferential (it saw the reviewer
  verdicts); the gate is what guarantees the outcome.
- **3D:** one run per probe, one model (GLM-5.2), no seed control. The clean win
  (`Jakso A → C`) is a confirmed preregistered prediction but a single sample —
  reliability unmeasured. Only GLM-5.2 tested; whether symmetric framing solves
  the cell on other families is open. The symmetric contract still lists B as an
  option (not a handed direction, but not absent). Not a production architecture —
  the framing was tested on one frozen cell + controls only.
- **3C:** one run per condition, one model (GLM-5.2), no seed control. The 2×2
  cross is one sample of each cell; the mechanism is located, not
  frequency-measured. F1 reproduces 3B.1 (blind spot run-stable across two runs).
  Masked condition preserves surrounding month *names* — "masked" = free of the
  target's own text, not all text (intentional; it is what makes M2 interpretable).
- **3B:** n = 1 alternative family for 3B.2 (llama3.1:8b). gemma4 frozen as
  fallback-only, never triggered (C1 was valid-but-wrong, not unparseable). The
  3B.2 negative is NOT evidence against model diversity generally — only against
  that one reviewer on that cell.
- One run per probe across the programme, no GLM seed control. Cannot distinguish
  always from once — but the Jakso A over-assertion replicated across three model
  families, two contracts, and (in 3C) two independent runs of F1, and the 3D/3E
  fix produced the opposite (C, then blocked failure) on one run each.
- The 3B.1/3C evidence-burden contract and 3D/3E symmetric contract were designed
  knowing the target (stated limitation); the controls (3B.1/3D/3E) and the
  four-condition contrasts (3C) are what make the results interpretable.
- Orchestrator foreknowledge persists from 3A; mitigated by frozen grading,
  verbatim traces, fresh isolated subagent contexts, the deterministic gate (no
  LLM overrides it in 3E), and the contrasts that a foreknown reviewer would have
  to satisfy consistently to fake a clean result.
